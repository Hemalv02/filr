# 🚀 Offline Feature - Quick Start

## What You Need to Know (30 Seconds)

### 🟢 Green Button = You're Online ✅
- Upload documents → They process immediately
- Everything works as expected
- Nothing to worry about!

### 🔴 Red Button = You're Offline ⚠️
- Upload documents → They're **saved safely** on your device
- They'll **upload automatically** when you're back online
- **Keep working normally** - no need to stop!

## Quick Test (1 Minute)

1. Open extension
2. See **green "Online"** button → You're connected ✅
3. Press **F12** → Open DevTools
4. Click **Network** tab → Select "**Offline**"
5. Watch button turn **red** and **pulse** → You're offline now 🔴
6. Upload a document → See it save to queue
7. Switch back to "**Online**"
8. Watch it **automatically sync** → Done! ✅

## FAQ

**Q: What if I close the browser while offline?**
A: Documents are saved in IndexedDB. They'll still be there when you reopen!

**Q: How do I know if sync worked?**
A: You'll see:
- Progress bar during sync
- Success toast after completion
- Document disappears from queue

**Q: What if a document fails?**
A: You'll see:
- Red "Failed" badge
- Error message explaining why
- "Retry" button to try again

**Q: Can I cancel a queued document?**
A: Yes! Click the "Cancel" button next to any queued item.

**Q: Do I need to do anything special?**
A: No! Just use the app normally. The offline feature works automatically.
